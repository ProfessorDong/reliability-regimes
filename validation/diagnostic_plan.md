# Post hoc diagnostics

The prespecified primary analysis and its numbers remain as recorded in `PROTOCOL.md` and `target_results.csv`. Two diagnostics address limitations of the near/far association.

1. Distinct standardized parents can share an identical fingerprint. Remove test parents having a nearest-training distance of zero, retain each compound's prespecified near and far weights, and renormalize each arm within each target. This diagnostic checks how much these parents contribute to the primary result and does not reconstruct strata after exclusion. Run `overlap.py`.
2. After observing different mean measured activity in near and far groups, on November 19, 2026 we specified an additional sensitivity analysis before examining its result. Within each primary target, fold, lead-set draw and lead-novelty stratum, keep its original near/far assignments and subdivide it by fixed nonoverlapping half-log-unit measured pActivity bins (floor of twice pActivity). Only cells containing at least one near and one far assignment contribute. Give the two sides the same cell weight proportional to cell size. Pool weighted squared errors before taking the square root on each arm, as in the primary comparison. Report included assignments divided by those contributing to the primary comparison, residual weighted average pActivity and novelty differences, and the per-target contrast with its conditional scaffold-group bootstrap interval. Use the same target-level summary as the primary analysis. This diagnostic uses held-out measured activity and has no prospective selection interpretation. Narrow bins equalize binned activity distributions while leaving possible within-bin residual differences. Run `activity_sensitivity.py`.
