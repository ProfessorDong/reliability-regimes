# Where and when a molecular property model can be trusted

Code, curated data, and frozen outputs for a study of when a machine-learned activity model
can be believed, across five targets relevant to therapy and molecular imaging: **SCD-1**,
**FADS** (endoplasmic-reticulum membrane lipid desaturases) and **NK1R**, **DRD2**, **DRD3**
(class A G-protein-coupled receptors).

Author: **Liang Dong**.

Every number in the manuscript and its Supplementary Information is produced by a frozen
analysis script run against a frozen output file, and is re-checked by `verify_results.py`
(93 assertions). The manuscript and SI read their numbers and tables from files generated by
`make_numbers.py` and `make_si_tables.py`, so no value is transcribed by hand.

## What this code establishes

The study measures reliability in two regimes, and they give different answers.

**Regime 1, within the pool the model was fitted from.** The disagreement among the trees of
a random-forest activity model ranks its measured error (Spearman 0.40 over 20,853
structure-disjoint predictions); retaining the lowest-disagreement fifth lowers RMSE by 42%.
Split conformal intervals reach nominal coverage, and disagreement-normalised intervals are
narrower at equal coverage. Novelty relative to the starting compounds is a weak predictor of
error once distance to the training set is accounted for, so compounds novel to the starting
leads but close to the wider training set retain low error.

**Regime 2, under temporal shift.** Training on compounds published before 2015 and testing
on 7,067 published later, error roughly doubles, the disagreement score ranks error at only
0.13 and on DRD3 not at all, and conformal coverage falls to 0.838 against a nominal 0.900.
Size-matched random splits recover coverage of 0.892 to 0.904 and the error ranking, so the
loss is distribution shift rather than sample size.

**Acquisition against real measured labels.** With all activities hidden except ten known
actives and a budget of 300 queries that each reveal a true measured value, selecting on the
predicted mean returns 3.9 times as many genuine top-percentile compounds as random selection
and an optimistic rule 4.2 times, while conservative lower-confidence and conformal-constrained
rules return 3.4 and 2.8 times. Penalising uncertainty costs true actives.

**Reported negative results.** The uncertainty term in the acquisition does not help; a
learned latent representation underperforms fingerprints; source-target compatibility does not
predict warm-start benefit; withheld-scaffold recovery is not improved by the triage.

## Reproducing the results

```bash
pip install -r requirements.txt

# 1. Build and gate the activity models (writes outputs/cwm_v1/oracle_{target}.pkl).
#    Required before any search experiment; the .pkl files are NOT in this repository
#    (see "Large files" below).
python -m world_model.oracle_sanity_gate

# 2. Reliability analyses (CPU only; these refit the models internally)
python -m world_model.standardize            # structure grouping (parent InChIKey)
python data/recurate_chembl_v2.py            # re-curate ChEMBL with provenance + years
python -m world_model.run_reliability_v2     # Regime 1: error stratification, risk-coverage
python -m world_model.run_conformal_v1       # Regime 1: calibrated intervals
python -m world_model.run_temporal_v1        # Regime 2: temporal shift + size-matched control
python -m world_model.run_poolopt_v1         # acquisition against real measured labels
python make_numbers.py && python make_si_tables.py   # regenerate all manuscript numbers/tables
python -m world_model.analyze_calibration      # sigma_T vs measured error
python -m world_model.run_applicability_v1     # distance-to-training, partial correlations
python -m world_model.run_reliability_v1       # measured error vs novelty; risk-coverage

# 3. Search experiments (need the .pkl activity models from step 1)
python -m world_model.run_frontier_v2          # novelty sweep x 2 optimizers x 2 penalties
python -m world_model.run_methods_v2           # primary method comparison (fingerprint surrogate)
python -m world_model.run_ecfp_baseline_v1     # fingerprint vs dual-encoder latent surrogate
python -m world_model.run_beta_ablation_v1     # uncertainty-acquisition ablation
python -m world_model.run_recovery_v2          # leakage-free scaffold-cluster recovery
python -m world_model.run_hierstats_v1         # hierarchical / target-level statistics

# 4. Check every reported number against the frozen outputs
python verify_results.py
```

`verify_results.py` asserts 60 numeric claims and exits non-zero on any mismatch.

## Data

The per-target datasets are curated from ChEMBL and the primary literature under a uniform
pipeline. Activities are pooled to pIC50; replicate ChEMBL measurements are aggregated to one
value per canonical structure before thresholding, while the SCD-1 literature-curated binding
set retains a small number of replicate records. FADS aggregates FADS1 and FADS2 desaturase
activity drawn mostly from a curated literature panel, so its activity function is the most
heterogeneous of the five.

Throughout, "few-seed" refers to the k in {5, 10, 20} starting active compounds supplied to
the search, not to the activity model, which is trained on all measured compounds for a target.

## Large files

The frozen activity models `outputs/cwm_v1/oracle_{target}.pkl` are not included: the DRD2
model exceeds the 100 MB per-file limit on GitHub. Rebuild them with
`python -m world_model.oracle_sanity_gate`, which reproduces them deterministically from the
data in this repository. The frozen JSON outputs that back the reported numbers are included,
so `verify_results.py` runs without rebuilding the models.

## A note on internal naming

The package directory (`world_model/`), some module and class names (`wm_guided_ga`,
`WMGuidedGA`, `LatentWorldModel`, `CWMReward`) and the keys of the frozen JSON outputs
retain identifiers from an earlier version of this work. They are kept unchanged so that the
frozen outputs and the reproduction path stay valid, and they carry no meaning beyond naming.
The primary method reported in the manuscript is the fingerprint-surrogate triage in
`run_methods_v2.py`.
